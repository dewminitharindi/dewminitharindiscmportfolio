# Dewmini Tharindi — Supply Chain Portfolio

A static single-page portfolio showcasing four applied supply chain management projects by Dewmini Tharindi, a student at SLTC Research University (2023–2027).

## Projects

1. **Campus Canteen Supply Chain Mapping** — field observation, flow diagramming, waste audit
2. **Small Pharmacy Inventory Study** — ABC classification, reorder point modelling, Power BI
3. **Kaggle Supply Chain Dataset Analysis** — data cleaning, KPI dashboard, Power BI
4. **Sri Lanka Tea Export Supply Chain** — secondary research, risk matrix, chain flow mapping

## Tech Stack

- Pure HTML/CSS/JavaScript — no build step, no framework
- Google Fonts (Playfair Display + Inter)
- Inline SVG for charts and diagrams
- IntersectionObserver for scroll-reveal animations

## Running Locally

Open `index.html` directly in a browser, or serve with any static file server:

```bash
npx serve .
```
